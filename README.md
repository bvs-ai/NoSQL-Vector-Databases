## Що потрібно

- Docker і Docker Compose (на Windows/macOS — Docker Desktop).
- На Windows скрипти `./lab.sh` запускайте з Git Bash або WSL.

Кожне демо піднімається однією командою `./lab.sh up` і прибирається `./lab.sh down`.
